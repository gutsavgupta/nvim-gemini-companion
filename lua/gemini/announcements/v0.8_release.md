# nvim-gemini-companion v0.8 — Claude Code Support! 🤖

Your companion now speaks **three** agents. Claude Code joins Gemini and Qwen — fully integrated, no extra setup.

## 🚀 What's New

### 🟣 Claude Code IDE Integration
- **Just works** — launch `claude` from the sidebar/tmux and it auto-connects to Neovim.
- **Native diffs** — Claude's edits open as real Neovim diff views; `:w` to accept, `:q` to reject.
- **Live context** — Claude sees your current selection, open files, and LSP diagnostics.
- **Secure by default** — connection is authenticated with a per-session token.
- **Reconnects** — a `claude` running in tmux re-attaches after a Neovim restart.

### 🔍 Smart Auto-Detection
No more listing agents by hand. By default the plugin enables **whichever CLIs you have installed** (`gemini`, `qwen`, `claude`). Set `cmds` only when you want to override.

### 🩺 Health Check
`:checkhealth gemini` now reports Claude status too — CLI installed, server port, auth, and lock file.

## ⚙️ Config Note
`cmds` is now optional. Leave it out to auto-detect, or pin your agents explicitly:
```lua
require("gemini").setup() -- auto-detects installed agents
-- or
require("gemini").setup({ cmds = { "claude", "gemini", "qwen" } })
```
